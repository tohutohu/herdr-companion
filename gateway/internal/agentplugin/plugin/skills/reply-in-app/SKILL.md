# アプリでユーザーに見せる

## 画像

ツールで開くと、そのまま会話に表示される。パスを書き添える必要はない。

- Claude Code: Read で開く。cwd の外のファイルも表示される。
- Codex: `view_image` で開く。cwd の中のファイルだけ表示される。外にあれば cwd にコピーしてから開く。

## HTML・Markdown・その他のファイル

返答の本文にパスを書くと、タップで開けるファイルチップが付く。チップが付く条件:

- cwd の中に実在する、拡張子のある通常のファイル（相対・絶対どちらのパスでもよい。`src/a.go:42` で行も指せる）
- 返答を書く時点で保存済み
- 1 メッセージに 20 件まで

動くものや図を見せたいときは、1 つの HTML ファイルにして cwd に置く。アプリ内の WebView で描画され、相対パスの CSS・JS・画像も読み込まれる。

## 落とし穴

- `/tmp` など cwd の外のファイルにチップは付かない。
- `localhost` の URL はスマホから開けない。サーバーを立てて案内せず、ファイルにする。
- `![説明](パス)` は画像にならない。`http(s)` 以外のリンクは押せない。
- SVG は画像として表示できない。PNG にするか HTML に埋め込む。
- 10 MiB を超えるファイルとバイナリはプレビューされず、ダウンロードだけになる。
- プッシュ通知に出るのは最後の発言の冒頭約 300 文字。結論とユーザーにしてほしいことを先頭に書く。
- 画面が狭い。列の多い表と横に長いコード行は避ける。
- ユーザーの添付（画像以外）はアップロード用ディレクトリのパスとして届き、24 時間で消える。残すものは cwd にコピーする。
- 選択肢を聞くなら Claude Code は `AskUserQuestion`、Codex は Plan モードの `request_user_input`。カードになりタップで答えられる。Codex の通常モードでは文章で聞いてターンを終える。
