# Herdr Companion アプリでの見え方

ユーザーはこの会話をスマホ（Android）か Mac のアプリで読んでいる。ターミナル・TUI・この Mac のブラウザは見えない。
外出先で、狭い画面で読んでいることが多い。

## 返答の書き方

- ターンの終わり・質問・承認待ちでプッシュ通知が出る。本文はセッション名と最後の発言の冒頭（約 300 文字）なので、結論とユーザーにしてほしいことを最初に書く。
- Markdown（見出し・リスト・コード・表・`[ラベル](https://…)` のリンク）は描画される。画面が狭いので、列の多い表や横に長いコード行は避ける。
- `![説明](パス)` は画像にならない。`http(s)` 以外のリンクは押しても開かない。画像は下の「画像を見せる」の方法で出す。
- `localhost` の URL はスマホからは開けない。HTML で見せたいものはファイルにして見せる。
- 選んでほしいときは質問ツールを使う（Claude Code: `AskUserQuestion`、Codex: Plan モードの `request_user_input`）。カードになり、タップで答えられる。ツールの承認もアプリから返せる。

## 画像を見せる

画像はツールで開くと、そのまま会話に表示される（作業ログに畳まれない）。タップすると全画面のビューアが開く。

- Claude Code: Read で画像ファイルを読む。画像は会話の記録に入るので、cwd の外（`/tmp` など）のファイルでも表示される。
- Codex: `view_image` で開く。cwd の中のファイルに限る。画像生成の結果もそのまま表示される。
- スクリーンショットを撮るツール（MCP など）が画像を返したときも同じように表示される。

見せる必要のない画像まで開くと会話が画像で埋まるので、ユーザーに見せたいものに絞る。

## ファイルを見せる

返答の本文にファイルのパスを書くと、メッセージにタップで開けるファイルチップが付く。

チップが付く条件:

- セッションの作業ディレクトリ（cwd）の中にある、実在する通常のファイル。cwd からの相対パスでも絶対パスでもよい。`src/a.go:42` のように行番号も付けられる。
- パスの末尾に拡張子がある（`Makefile` のような拡張子のない名前は拾われない）。URL（`://` や `www.` を含むもの）は対象外。
- 返答を書いた時点でファイルがある（先に保存してから書く）。1 メッセージにつき 20 件まで。
- `/tmp` など cwd の外のファイルは見せられない。スクリーンショットや生成物は cwd の中（例: gitignore 済みのディレクトリ）に保存する。`.ssh` `.gnupg` `.aws` の中は配信されない。

開いたときの表示:

| 種類 | 表示 |
|---|---|
| 画像（PNG・JPEG・GIF・WebP） | ピンチとダブルタップでズームできるビューア。SVG は表示できないので PNG にする |
| HTML | アプリ内の WebView で描画。同じフォルダの相対パスの CSS・JS・画像も読み込む。ソースも見られる |
| Markdown | 描画される（ソースに切り替えられる） |
| その他のテキスト | シンタックスハイライト付き。行番号があればその行を開く |
| 10 MiB を超えるもの・バイナリ | プレビューなし。ダウンロードだけできる |

Read・Edit・Write したファイルにもチップが付く。ただしツール呼び出しは 1 行に畳まれるので、見せたいファイルは返答の本文にも書く。

## ユーザーから届くもの

- ユーザーが添付した画像はそのまま画像として届く。ほかのファイルは Gateway のアップロード用ディレクトリに保存され、そのパスがメッセージの末尾に入る。アップロードは 24 時間で消えるので、残すものは cwd にコピーする。
- 他のセッションや常駐タスクからのメッセージが届くこともある。セッションの操作は `herdr-companion:hc` スキルを参照。
